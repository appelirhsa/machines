🔋 DC Machines

Principles & types, EMF/torque equations, losses & efficiency, and speed control (including Ward-Leonard).

1. Basic principle & construction

A DC machine has a stationary field (permanent magnet or field winding, producing flux φ) and a rotating armature carrying conductors that cut this flux. It is fully reversible:

  • Generator action: the shaft is driven mechanically → conductors cut flux → an EMF is induced (Faraday's law) → current flows into an external circuit.
  • Motor action: current is driven through the armature conductors sitting in the field → a force (F = BIl) is produced on each conductor → torque is developed on the shaft.
Whether a given machine is "acting as" a motor or generator depends only on the direction of power flow at that instant — not on its physical construction.

2. The EMF equation

For an armature with Z total conductors, P poles, A parallel paths, flux per pole φ (Wb), running at N rpm:

\[ E = \frac{\phi Z N}{60}\left(\frac{P}{A}\right) \]
Winding typeParallel paths, AEffect
LapA = PP/A = 1 → lower voltage, higher current capability (more parallel paths)
WaveA = 2P/A = P/2 → higher voltage, lower current capability

Since E ∝ φN (for a fixed machine), you can also write E2/E1 = (φ2N2)/(φ1N1) — extremely useful for "what happens if speed/flux changes" questions without recomputing from scratch.

Worked example

A 4-pole, lap-wound armature has 728 conductors and runs at 1800 rpm; flux/pole = 30 mWb. Find the induced voltage.

  1. Lap wound → A = P = 4, so P/A = 1.
  2. E = φZN/60 = (0.030)(728)(1800)/60.
  3. E = 655.2 V.

If the same armature were wave-wound instead (A=2), E would be multiplied by P/2 = 2, giving 1310.4 V — same conductors, same flux, same speed, but a completely different terminal voltage. This is a classic exam trick — always check the winding type before applying the formula.

3. Torque, developed power, and losses

\[ P_d = E I_a = T_e \omega_m \qquad T_e = k_a \phi I_a \]

where ωm = 2πN/60 (rad/s). This is the electromechanical energy-conversion link: the same power that "disappears" electrically as E·Ia reappears mechanically as torque times speed.

Loss breakdown

\[ \eta = \frac{\text{Output}}{\text{Input}} = \frac{\text{Output}}{\text{Output}+\sum \text{losses}} \]
Maximum efficiency occurs when the variable loss (Ia²Ra) equals the constant loss Pc: at that point, Ia = √(Pc/Ra).
Worked example

A 100 kW, 230 V shunt generator has Ra=0.05 Ω, Rf=57.5 Ω, and 1.8 kW rotational loss. Find full-load efficiency.

  1. If = 230/57.5 = 4 A. IL = 100000/230 = 434.8 A. Ia = IL+If = 438.8 A.
  2. If²Rf = 0.92 kW. Ia²Ra = 9.63 kW. Total losses = 0.92+9.63+1.8 = 12.35 kW.
  3. η = 100/(100+12.35) = 89%.

4. Types of DC machine & their torque–speed behaviour

TypeField connectionTorque–speed characterTypical use
Separately excitedIndependent supplyNearly linear speed drop with load torque; flux fixed by external controlPrecise speed/torque control, Ward-Leonard, servo drives
ShuntField in parallel with armature"Fairly flat" — speed drops only slightly with loadConstant-speed applications (fans, machine tools)
SeriesField in series with armatureFlux ∝ Ia (unsaturated) → very high starting torque, speed falls steeply as load rises; never run unloaded (can overspeed dangerously)Traction (trains, cranes, starter motors)
Compound (cumulative)Both shunt & series fields, aidingBetween shunt and series — good starting torque + speed regulationElevators, rolling mills, presses
Compound (differential)Series field opposes shuntSpeed rises with load — rarely used, can be unstableSpecial constant-speed applications
Permanent magnet (PM)Flux from magnets, constantLinear T–ω line, like separately-excited with fixed φ; E ∝ n directlySmall motors, servo & robotics, EV auxiliary drives

Short-shunt vs long-shunt compound: in short-shunt, the shunt field is connected directly across the armature (series field carries only load current outside that loop); in long-shunt, the shunt field is across the series combination of armature + series field. The difference shows up in exactly where Ia vs IL is used in the voltage/current equations — always redraw the circuit for these problems.

For a PM motor, φ is constant, so E ∝ n and T ∝ Ia directly — this makes "find the new speed given a new voltage/current" problems solvable purely from E = V − IaRa and n₂ = n₁(E₂/E₁).

5. Speed control & the Ward-Leonard system

\[ n = \frac{E}{k_a\phi} = \frac{V-I_aR_a}{k_a\phi} \]

Three classic ways to change speed, visible directly in this equation:

  • Field control — reduce φ (field weakening) → speed rises. Torque capability falls for the same Ia (constant-power region above base speed).
  • Armature resistance control — insert resistance in series with the armature → E (and hence n) drops for the same V, but wastes power as heat in the resistor. Simple, cheap, inefficient.
  • Armature voltage control — vary V directly (e.g. via a controlled rectifier, chopper, or the Ward-Leonard generator) → speed changes with good efficiency and full torque available at any speed up to base speed.
Ward-Leonard system: A separately-driven DC generator supplies a DC motor's armature directly. The generator's own (small) field current/voltage is varied to set the generator's output voltage, which sets the motor's armature voltage and hence its speed — smooth, continuously variable, reversible speed control historically achieved without power electronics. The transfer function relates field voltage input to motor speed output through the generator, motor, and load inertia/damping.
Worked example — PM motor speed scaling

A PM motor runs at 1400 rpm on 10 V, drawing 7 A (Ra = 0.2 Ω). Find the speed on 12 V drawing 8 A, same mechanical load type.

  1. E₁ = V₁ − I₁Ra = 10 − (7)(0.2) = 8.6 V.
  2. E₂ = V₂ − I₂Ra = 12 − (8)(0.2) = 10.4 V.
  3. Since φ is constant: n₂ = n₁ × (E₂/E₁) = 1400 × (10.4/8.6) ≈ 1693 rpm.
